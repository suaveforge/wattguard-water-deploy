# Public Deployment
This repository is a **static mirror** of the private source repository `suaveforge/wattguard-water`.

App: root. Evidence: `/#/evidence` (hash router). All chart values, events and equipment readings are synthetic test data. This repository **does not** connect to K-water, SCADA, public emergency alert systems or physical equipment.

The included GitHub Actions Pages workflow requires: Settings → Pages → Build and deployment → Source: **GitHub Actions**. The custom domain `wattguard-water.suaveforge.com` requires DNS and explicit Pages configuration; it is **not** automatically live just because the source code has been committed.
